## Aprendizados
- A documentação do Gemini mostra uma API nova (`interactions`), mas o SDK 2.22.0 mantém `models.generateContent` ([[DEC-007 Gemini 2.5 Flash como modelo inicial]]).
- O preview do Claude procura `launch.json` na pasta da sessão (`SAC/.claude`), não na do projeto.
- Quando o servidor já está rodando no terminal do Lucca, usar a entrada `sac-ia-academico (terminal)` do `launch.json`, que só se conecta a `http://localhost:3000` sem abrir outro processo.
- Buscas sobre "Alfenas" misturam UNIFENAS e UNIFAL ([[Fontes da UNIFENAS]]).
